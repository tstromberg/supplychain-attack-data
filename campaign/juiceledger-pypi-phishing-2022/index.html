JuiceLedger phished PyPI maintainers

Campaign: juiceledger-pypi-phishing-2022
Date: 2022-08-24
Actor: JuiceLedger (group)
Impact: credential_theft, data_exfiltration

Synopsis

JuiceLedger phished PyPI maintainers and published malicious releases under real package names. The known legitimate-package compromises were exotel 0.1.6 and spam 2.0.2 and 4.0.2.

Story

The JuiceLedger PyPI incident began with a simple trust failure. Maintainers received phishing mail that claimed PyPI required package validation. The login page was false; the credentials were real.

With those credentials, the attackers published malicious releases under legitimate package names. PyPI identified exotel 0.1.6 and spam 2.0.2 and 4.0.2 as poisoned releases, while also removing hundreds of typosquats that used the same pattern but sit outside this dataset's scope.

The payload collected environment details and pulled a larger trojan at install time. The registry did not need to be broken. A maintainer account was enough to turn package installation into code execution.
