Synopsis

A Pwn Request flaw let attacker-controlled PR code run with kubernetes-el repository privileges. The stolen token defaced the repo and replaced kubernetes.el with a destructive shell command.

Story

The attack began with an ordinary-looking pull request. kubernetes-el used `pull_request_target`, then explicitly checked out the pull request head. That combination ran attacker code inside a privileged GitHub Actions context.

The payload evolved in the open. The attacker changed the Makefile to run `funny.sh`, tried runner memory dumping, switched tooling, fixed build syntax, and finally extracted GitHub Actions secrets to webhook.site. The important secret was the writable `GITHUB_TOKEN`.

With that token, commits appeared as `github-actions[bot]`. The README was defaced, then `kubernetes.el` was replaced with an Emacs expression that invoked `rm -rf /`. For users installing or updating from the repository mirror path, source code became the delivery channel.

The compromise was reported by Emacsmirror maintainer Jonas Bernoulli on March 7, 2026. MELPA removed the package and Emacsmirror blocked updates, limiting the damage to a narrow window.
