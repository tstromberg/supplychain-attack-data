Synopsis

rand-user-agent 1.0.110, 2.0.83, and 2.0.84 carried obfuscated RAT code. The payload connected to attacker C2 and exposed shell and file-upload commands.

Story

Aikido detected the first malicious `rand-user-agent` release on May 5, 2025 at 16:00 UTC. The project repository still pointed at older clean source, but npm held newer package versions with code that did not belong.

The attacker hid the first stage in `dist/index.js`, using obfuscation and horizontal scroll space to bury the payload in a file reviewers might skim. After decoding, the code installed or loaded `axios` and `socket.io-client` under a custom `.node_modules` path in the user's home directory.

The payload behaved as a remote access trojan. It connected to `85.239.62.36:3306`, uploaded files through `85.239.62.36:27017/u/f`, sent hostname and username details, accepted directory and upload commands, and executed arbitrary shell input through `child_process.exec()`.

On Windows, it also prepended `%LOCALAPPDATA%\Programs\Python\Python3127` to `PATH`, giving the attacker a quiet way to influence commands that resolved Python tooling by name. The affected npm versions were 1.0.110, 2.0.83, and 2.0.84.
