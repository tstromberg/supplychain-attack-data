Synopsis

After the Essential Plugin, formerly WP Online Support, portfolio was sold on Flippa, the new owner gained WordPress.org commit access and planted a dormant PHP backdoor across the plugin family.

Story

Essential Plugin was not a single plugin failure. A portfolio of WordPress.org plugins changed hands after a Flippa sale, and the new owner received the project access needed to ship updates through the official plugin directory.

The malicious code was planted across the plugin family beginning in August 2025. It sat dormant for months, then activated in early April 2026. That delay made the change look like ordinary maintenance until many sites already had the backdoor installed.

The backdoor used the `wpos-analytics` code path and contacted `analytics.essentialplugin.com`. Public analysis described an unauthenticated REST endpoint, weak permission callbacks, and payloads that could write files such as `wp-comments-posts.php` or modify `wp-config.php`.

WordPress.org closed the Essential Plugin portfolio on April 7, 2026, then pushed neutralizing updates on April 8. The event matters because ownership transfer was the trust boundary: the code was distributed through real plugins under an authorized account.
