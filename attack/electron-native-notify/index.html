Synopsis

`electron-native-notify` was published as useful npm code, then changed to steal Agama wallet seeds after the target adopted it.

Story

`electron-native-notify` was not a random poisoned package. npm described it as a staged attack: publish a useful module, get it accepted into the Agama build chain, then update the module with the payload.

Version 1.1.6 introduced the malicious behavior on March 23, 2019. The code targeted cryptocurrency applications, collected wallet seeds and passphrases, and sent them to a remote server. That made the package a key thief, not a general backdoor.

The package reached Agama through EasyDEX-GUI and became dangerous when Agama released with the dependency. npm detected the threat, coordinated with Komodo, and removed the malware from the registry.

The package-level record matters because the same artifact explains the downstream Agama loss. The wallet record carries the fund movement and user impact; this record carries the poisoned npm object and the method.
