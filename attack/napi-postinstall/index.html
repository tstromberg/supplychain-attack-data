Synopsis

napi-postinstall 0.3.1 was published during the July 2025 npnjs.com maintainer phishing wave. Its install path executed attacker-controlled JavaScript from npm.

Story

The `napi-postinstall` compromise belongs to the npnjs.com phishing campaign. Maintainers were lured to a lookalike npm login flow, and stolen credentials were used to publish malicious versions across JavaScript tooling packages.

For this package, the affected artifact was `napi-postinstall@0.3.1`. The danger was the install path: npm lifecycle execution gave the payload a chance to run on developer machines and CI systems as soon as the package was installed.

StepSecurity listed the package among the affected releases while analyzing the eslint-config-prettier compromise, and Socket tracked the same phishing wave across the registry. The package itself is recorded separately so lockfiles and artifact inventories can point to the exact release.

The campaign record carries the shared phishing infrastructure and cross-package pattern. This record carries the concrete npm package and version.
