Synopsis

Octopus Scanner backdoored 26 NetBeans projects on GitHub. The malware infected build artifacts and propagated when developers built already-compromised projects.

Story

GitHub Security Lab disclosed Octopus Scanner in May 2020 after finding 26 affected open-source NetBeans projects. The malware targeted a developer workflow rather than a runtime server.

Once present in a NetBeans project, Octopus Scanner modified build files and planted a payload so future builds produced infected JARs. Developers who cloned and built a compromised project could spread the infection into their own build outputs.

The malware also installed remote-access capability, turning the build step into a persistence and access path. That made it a source-level supply-chain attack: the repository looked like the product, but the build product carried something else.

GitHub removed affected projects and published indicators for defenders. This record treats the 26 projects as artifact scope, not as a human victim count.
