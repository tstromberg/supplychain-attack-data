Synopsis

A Volusion-hosted script in Google Cloud Storage was modified with Magecart code. Roughly 29,500 storefronts inherited the payment skimmer.

Story

Volusion served common storefront JavaScript from a Google Cloud Storage bucket. In October 2019, attackers modified `volusion.js`, a script loaded by merchants on the hosted ecommerce platform.

The injected code loaded a skimmer from `gogogolo.com`. On checkout pages, it collected payment-card data and sent it to attacker infrastructure. Customers saw the merchant storefront; the compromised dependency lived underneath it.

Trend Micro reported more than 29,500 affected Volusion-hosted sites. The scale came from centralization: one platform script was reused across many stores, so one storage-object compromise became many checkout compromises.

This record is scoped to the hosted Volusion script, not to individual merchant breaches. The artifact was a production JavaScript dependency served from Volusion-controlled cloud storage.
