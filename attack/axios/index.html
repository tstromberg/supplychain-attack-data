Synopsis

A compromised axios maintainer account published malicious npm versions 1.14.1 and 0.30.4 on March 31, 2026. Both releases injected plain-crypto-js 4.2.1, whose install path delivered a multi-platform RAT and exposed machines that installed the brief releases.

Story

The axios compromise was short, but it sat on a very large dependency graph. On March 31, 2026, an attacker used the lead maintainer's npm access to publish axios 1.14.1 and 0.30.4. The project later described the entry point as a compromised maintainer machine reached through targeted social engineering and RAT malware.

The malicious axios releases did not need to rewrite the library's public API. They added a dependency on plain-crypto-js 4.2.1, moving the payload into dependency resolution and install-time execution. A normal fresh install during the window could pull the poisoned axios version, then pull the malicious helper package from npm.

The payload was a remote access trojan for macOS, Windows, and Linux. The postmortem told affected users to inspect lockfiles for axios 1.14.1, axios 0.30.4, or plain-crypto-js, remove the malicious dependency, check for traffic to sfrclak[.]com or 142.11.206.73 on port 8000, and rotate every secret available to the affected machine or CI runner.

The timeline was measured in hours: axios 1.14.1 appeared at 00:21 UTC, axios 0.30.4 around 01:00 UTC, community detections followed almost immediately, and npm removed the malicious axios versions by 03:15 UTC. The project response moved toward immutable releases, OIDC publishing, stronger GitHub Actions hygiene, and a release process less dependent on one personal account.
