Synopsis

FossHub's distribution platform was compromised, and Classic Shell downloads were swapped for a destructive installer.

Story

Classic Shell was hit through its download host. On August 2, 2016, FossHub served a malicious Windows installer in place of the legitimate application. Users followed the normal project download path and received a payload built to damage the machine.

The replacement binary was not a subtle implant. Public analysis and user reports tied it to an MBR-wiping program that overwrote boot structures and left systems unable to start cleanly. The payload presented itself as the requested installer, then attacked the host.

FossHub took affected downloads offline and Classic Shell warned users not to run packages fetched during the compromise window. The incident was short, but the blast radius was broad because FossHub was a shared distribution service for multiple open-source Windows projects.

This record tracks Classic Shell as one affected project, not the whole FossHub event. The trust boundary was the official distribution path: source code did not need to change when the download service could be made to serve a hostile executable.
