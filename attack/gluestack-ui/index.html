Synopsis

A leaked npm token let attackers publish 17 malicious React Native ARIA and gluestack-ui packages. The code carried obfuscated RAT behavior but was contained quickly.

Story

The gluestack incident started with `@react-native-aria/focus@0.2.10` on 2025-06-06. Over the next day, the attacker published malicious versions across React Native ARIA and `@gluestack-ui/utils`, reaching 17 package versions with more than one million combined weekly downloads.

Gluestack attributed the compromise to an npm access token that lacked two-factor protection. The attacker used that token to publish existing package names, not typosquats, so normal dependency resolution could deliver the poisoned releases.

The payload was obfuscated JavaScript with remote-access behavior. Public reports described whitespace hiding, encoded JavaScript, fake Python persistence paths, metadata harvesting, command execution, and C2 endpoints on `136.0.9.8` and `85.239.62.36`.

The exposure window was short. Aikido reported the compromise, the team revoked tokens, deprecated affected versions, restricted access, and published clean replacements. Gluestack reported no confirmed system-level compromises or data exfiltration.
