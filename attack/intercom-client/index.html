Synopsis

The Mini Shai-Hulud/TeamPCP campaign compromised the official intercom-client package on npm.

Story

`intercom-client@7.0.4` was published on 2026-04-30 through a hijacked GitHub Actions OIDC publishing path. StepSecurity treated it as direct evidence that Mini Shai-Hulud was propagating through CI/CD tokens stolen from earlier victims.

The package stayed functional but changed shape. Version 7.0.4 added a `preinstall` hook, introduced `setup.mjs`, and shipped an 11.7 MB single-line `router_runtime.js` payload. The clean 7.0.3 release had SLSA provenance; the malicious 7.0.4 release did not.

The loader downloaded Bun 1.3.13 and used it to execute the obfuscated payload. The stealer expanded beyond GitHub and npm tokens into AWS metadata, GCP metadata, Azure connection strings, private keys, environment variables, and generic API-key patterns.

Exfiltration used GitHub itself. The payload authenticated to `api.github.com`, created a private repository under the victim account, and committed encrypted stolen data there. That made ordinary egress filtering weak: the traffic went to a domain many CI systems already allow.
