Synopsis

Attackers exploited a misconfigured pull_request_target workflow in the Trivy GitHub repository. An autonomous bot named hackerbot-claw stole a Personal Access Token (PAT). TeamPCP maintained access and injected credential stealers into 75 release tags and Docker images, expanding to push malicious Docker images (0.69.4, 0.69.5, 0.69.6) to Docker Hub bypassing the normal release process.
