Synopsis

The Mini Shai-Hulud campaign expanded into the PHP ecosystem by compromising the official intercom/intercom-php package on Packagist. Attackers compromised a maintainer account to overwrite existing legitimate versions.

Story

`intercom/intercom-php@5.0.2` showed Mini Shai-Hulud crossing ecosystem boundaries. Semgrep reported that attackers overwrote an existing legitimate Packagist version rather than publishing a new obvious outlier.

The malicious package converted itself into a Composer plugin. That matters because Composer plugins execute during installation, before application code imports the library. The install step became the execution step.

The plugin downloaded the Bun JavaScript runtime and ran an obfuscated credential stealer aligned with the npm campaign. The payload targeted GitHub tokens, SSH keys, cloud credentials, environment variables, and other developer secrets.

The record is paired with `intercom-client` because both appeared the same day and shared Mini Shai-Hulud tooling. It remains separate because the compromised artifact, package manager, and execution mechanism were different.
