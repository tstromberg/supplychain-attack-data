Synopsis

Glassworm published @aifabrix/miso-client 4.7.2 with invisible Unicode JavaScript. The code looked empty in review but decoded to malware at runtime.

Story

Glassworm's March 2026 wave hid code in characters people do not see. The `@aifabrix/miso-client` package carried the same invisible Unicode decoder pattern Aikido tracked across npm, VS Code, and GitHub repositories.

The visible JavaScript looked harmless because the payload lived inside variation selector characters. At runtime, a decoder converted those hidden code points back into bytes and passed the result to `eval`.

Aikido listed `@aifabrix/miso-client@4.7.2` as one of the npm artifacts published on 2026-03-12. The broader Glassworm pattern used staged loaders, Solana-based dead drops, and credential theft from developer environments.
