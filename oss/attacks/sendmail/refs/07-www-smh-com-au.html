Trojan horse in Sendmail source code

October 9, 2002 — 10:00am

You have reached your maximum number of saved items.

Remove items from your saved list to add more.

Some copies of the source code for the Sendmail package have been modified by an intruder to contain a Trojan horse, according to an advisory from the CERT Coordination Center, a centre of Internet security expertise.

Sendmail is the most widely used mail transport agent on the Internet and is estimated to transport around 80 percent of the world's email.

CERT has advised sites that employ, redistribute, or mirror the Sendmail package to immediately verify the integrity of their distribution.

The CERT advisory said the files sendmail.8.12.6.tar.Z and sendmail.8.12.6.tar.gz had been modified to contain the malicious code.These files began to appear in downloads from the FTP server ftp.sendmail.org around September 28.

It said the Sendmail development team disabled the compromised FTP server on October 6.

The advisory said the Trojan horse versions of Sendmail contained malicious code that was run while building the software. This code forked a process that connected to a fixed remote server on port 6667/tcp. This forked process allowed the intruder to open a shell running in the context of the user who built the Sendmail software.

There was no evidence that the process persisted after the compromised system was rebooted but a subsequent build of the Trojaned package would re-establish the backdoor process.
