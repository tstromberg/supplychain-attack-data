Security Alert: Malicious npm Release Detected in v0.3.91#11
Copy link

Description

sailikhith-stepsecurity
opened on Mar 16, 2026
Issue body actions

Summary

A suspicious release (v0.3.91) has been published to npm for react-native-country-select that appears to contain malware. This version was not released through the normal GitHub workflow and has been flagged by security analysis systems. More Details can be found here: https://www.stepsecurity.io/blog/malicious-npm-releases-found-in-popular-react-native-packages---130k-monthly-downloads-compromised

Evidence

1. Release Not from GitHub Workflow

  • Version 0.3.91 was published directly to npm without a corresponding GitHub release
  • Version 0.3.91 appears to bypass the standard release process

2. Security Analysis Flags Malware

StepSecurity AI Package Analyst has flagged this package:

  • Analysis Report: https://app.stepsecurity.io/oss-security-feed/react-native-country-select?version=0.3.91

3. New Install Scripts Added

Version 0.11.8 has added new pre install scripts and is executing it which is heavily obfuscated - https://npmdiff.dev/react-native-country-select/0.3.9/0.3.91

Recommended Actions

For Maintainers (@AstrOOnauta)

  1. Deprecate v0.3.91 on npm:

    npm deprecate react-native-country-select@0.3.91 "Security: Malicious code detected. Do not use. See GitHub issue."

  2. Please Investigate the compromise:

    • Check npm account access logs
    • Review who has publish access to the package
    • Verify if your npm token was compromised
    • Check if your development machine was compromised
    • Investigate how version 0.3.91 was published

  3. Secure your npm account:

    • Enable 2FA if not already enabled (mandatory for npm packages)
    • Rotate npm access tokens immediately
    • Review and revoke any suspicious npm tokens
    • Audit all collaborators with publish access
    • Check for any unauthorized account access

  4. Publish a clean version:

Related Issue

This package is a dependency of react-native-international-phone-number, which also has a suspicious release (v0.11.8). See related security issue in that repository.
